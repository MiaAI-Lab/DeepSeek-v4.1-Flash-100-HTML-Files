TITLE: Echo Field — An Instrument for Seeing Sound

PROMPT:
Create "Echo Field," a self-contained audio-visual instrument that lets a visitor see sound. Use a warm gallery-white ground, electric ultramarine serif typography, vermilion accents and fine black line work. Build an airy full-screen composition with a central field of concentric shimmering rings, a large "Echo field" headline, instrument metadata, vertical acoustic notes, a live frequency readout, and five note apertures (A, C, D, E, G). Clicking or tapping the field should emit a colored ripple and, when sound is enabled, play a soft synthesized bell tone. Add a sound enable/mute control. Keep all effects inline with Canvas 2D, CSS and a small Web Audio synth; handle unsupported audio gracefully. Responsive, offline, no external assets, libraries or fonts. Valid HTML5.

DESCRIPTION:
An elegant imaginary acoustic instrument: hand-drawn-looking rings breathe in a white room while ultramarine and vermilion type frame the field. Touching the page produces both a visible wave and a gentle overtone, turning the screen into a meditative listening space.

MAJOR VISUAL TECHNIQUES:
- Animated Canvas rings with breathing radii and drifting orbital ellipses
- Generative sound feedback using a tiny Web Audio sine/triangle synth
- Gallery-editorial composition with oversized blue serif type
- Fine data labels, signal waveform and live state changes
- Responsive control layout and cursor-linked resonance line

INTERACTION MODEL:
Click or tap anywhere in the field to send out a ripple and hear the currently selected note. Select one of five circular note buttons to retune the instrument and trigger a visible pulse. Enable sound with the control; all audio is generated in the browser and begins only after a user gesture.
