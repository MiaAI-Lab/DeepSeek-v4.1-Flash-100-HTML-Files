TITLE: Patchbay — A Modular Instrument

PROMPT:
Create "Patchbay," a self-contained modular synthesiser interface with the dense, tactile beauty of a Eurorack case. Use charcoal metal, panel greys, cream legends and four patch-cable accent colors: orange, mint, blue and pink. Build an eight-module rack (Oscillator, Filter, Envelope, Echo, Waveform/8-step, Input, Mixer, Output), each with knobs, jack sockets and tiny technical legends. Include a live canvas oscilloscope, an eight-step sequencer, a Run transport, a Randomise control, a Clear Patch control and master readouts for BPM, active voices and level. Click any two jacks to create a cable; knobs can be turned with the mouse wheel or clicked. All graphics and logic inline; no external assets, fonts, libraries or audio files. Responsive, offline, valid HTML5.

DESCRIPTION:
A love letter to hardware that clicks and glows. The interface is dense but legible, and the act of patching two sockets together creates a satisfying sense of cause and effect.

MAJOR VISUAL TECHNIQUES:
- Detailed modular panel styling with inset shadows and metallic gradients
- Rotatable CSS knobs driven by custom properties
- Canvas oscilloscope responding to patch count
- Step sequencer with running playhead
- Patch list, status LEDs and technical micro-typography

INTERACTION MODEL:
Click a jack to select it, then click another jack to run a patch cable; cables are listed and the scope updates. Scroll on any knob to turn it, or click for a random setting. Run starts the 8-step sequencer with a moving playhead; Randomise generates a new pattern and tempo; Clear Patch removes all cables.
