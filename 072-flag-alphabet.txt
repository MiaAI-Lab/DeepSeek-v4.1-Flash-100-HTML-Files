TITLE: Signal Tower 072 — A Two-Flag Alphabet

PROMPT:
Create "Signal Tower 072," a self-contained coastal signalling lesson that turns the alphabet into two-flag gestures. Use sea blue-green, signal vermilion, bone cream, navy and brass. Compose a three-column station: an editorial "Flag alphabet" title with the rule (eight positions, taken two at a time, twenty-eight combinations); a sea horizon with a silhouetted signalman on a platform, two rotating arms with rectangular flags, a letter badge and position readouts; and a seven-column alphabet keypad, a message strip, transmit/delete/clear controls and a compact code table. Clicking or typing a letter should rotate both arms to that letter's pair of positions and append it to the message. Transmit should step through the message letter by letter at a readable pace. No external assets, images, fonts, libraries or network calls. Responsive, offline, valid HTML5.

DESCRIPTION:
A signalling lesson you can perform. The figure is built from simple shapes, the flags are plain rectangles, and the code is fully visible — which makes the page feel like an instrument rather than an illustration.

MAJOR VISUAL TECHNIQUES:
- CSS signalman with rotating arms and flags over a gradient sea horizon
- Position-to-angle mapping for eight arm positions
- Systematic letter table from combinations of two positions
- Message composition by click, keyboard or keypad
- Timed transmit sequence with live progress

INTERACTION MODEL:
Click any letter button, or press a letter key, to pose the arms and add that letter to the message. Space adds a gap; Backspace deletes. Transmit animates through the message; Clear empties it. Position numbers and the pair code update with every gesture.
